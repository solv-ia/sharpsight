# Sharp Sight

React website for Sharp Sight, a Greater Tampa Bay residential home inspection brand focused on home inspections, thermal imaging, buyer-ready reports, and real estate agent workflows.

## Launch Focus

- Home inspections
- Thermal imaging
- Buyer and agent-friendly reporting
- Greater Tampa Bay service-area positioning

## Coming Soon Services

- 4-point inspections
- Wind mitigation
- Roof certifications
- WDO coordination
- Sewer scopes
- Pool and spa
- Mold and air quality
- New construction
- 11-month warranty
- Commercial inspections
